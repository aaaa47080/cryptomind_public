# Community Engagement and TON Ecosystem Guidance

## When to Use
When the user asks about platform community features or TON operations:
- "How do I post in the forum?"
- "How do I tip someone?"
- "What are the benefits of Premium?"
- "How do I connect a TON wallet?"
- "How do I use the forum?"

## Method

### Step 1: Identify the user's intent
Determine which of the following the user wants to understand:
1. Forum features (post / reply / categories)
2. Tipping system (TON tipping)
3. Membership tier (Free vs Premium)
4. Wallet operations (TON Connect)
5. Social features (friends / DM)

### Step 2: Provide operation guidance

#### Forum posting
- Go to the "Forum" tab → click "Post"
- Choose a board (Crypto / US Stocks / TW Stocks / General / Trading Strategies)
- Free members pay 0.1 TON per post; Premium is free
- Supported categories: Analysis / Question / Tutorial / News / Casual / Review
- Tags can be added (#BTC #ETH) for easier discovery

#### TON tipping
- On the article page, click the "Tip" button
- Enter the amount → confirm via TON Connect → on-chain transfer
- Tips are direct P2P, not routed through the platform
- You cannot tip your own article

#### Premium membership
| Feature | Free | Premium |
|------|------|---------|
| Read articles | ✅ | ✅ |
| AI analysis | ✅ | ✅ |
| Posting | 0.1 TON/post | Free |
| Reply / Vote | 20/day | Unlimited |
| DM | ❌ | ✅ |
| AI long-term memory | ❌ | ✅ |
| Advanced tools | ❌ | ✅ |

#### TON Connect
- Settings page → bind a TON wallet
- Tonkeeper wallet is recommended
- After binding you can: upgrade to Premium / tip / receive tips / post

### Step 3: Guide ecosystem participation
- Encourage high-quality posts (analysis, reviews)
- Explain the reputation system (upvotes/downvotes affect reputation)
- Safety reminder: beware of scams; use the "Security" tab to report suspicious wallets

## Output Format
Answer in natural conversational language; no table format needed (unless comparing plans).

The tone should be friendly, like a friend introducing the platform — not a customer-service script.

## Conventions
- If the user has not bound a wallet, guide them through binding first before explaining paid features
- Tipping and posting fees should be stated in TON (not fiat)
- Premium upgrade is a monthly subscription; remind about renewal
- Safety reminder: never click unknown links, never share your private key with anyone
